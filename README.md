# Solana NFT Marketplace

NFT marketplace on Solana: an **Anchor (Rust)** program that holds each NFT in a PDA escrow until it
is sold or delisted, pays the marketplace fee and Metaplex royalties on every sale, and a **Next.js**
frontend to explore, sell, buy and administer it. Deployed on Devnet.

Marketplace de NFTs en Solana: un programa **Anchor (Rust)** que custodia cada NFT en un escrow PDA
hasta que se vende o se cancela, paga la comisión del marketplace y las royalties de Metaplex en cada
venta, y un frontend **Next.js** para explorar, vender, comprar y administrar. Desplegado en Devnet.
